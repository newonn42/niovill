휴대폰 알림

새 상담 신청이 오면 이 휴대폰 알림창에 바로 뜹니다. 알림을 받을 휴대폰마다 한 번씩 켜 주세요.

아이폰은 이 화면을 홈 화면에 추가한 뒤에만 알림을 받을 수 있습니다.

  1. 이 주소를 Safari로 엽니다
  2. 아래쪽 공유 버튼(네모에 위쪽 화살표)을 누릅니다
  3. 홈 화면에 추가 → 오른쪽 위 추가를 누릅니다
  4. 홈 화면에 생긴 니오빌 관리 아이콘으로 엽니다 (로그인을 한 번 더 해야 합니다)
  5. 설정 탭 → 이 휴대폰에서 알림 켜기를 누르고 허용을 누릅니다

iOS 16.4 이상에서 됩니다 (설정 → 일반 → 정보 → iOS 버전)

이 브라우저는 알림을 지원하지 않습니다. 갤럭시는 크롬 또는 삼성 인터넷으로 열어 주세요.

알림이 차단되어 있습니다. 휴대폰 설정 → 애플리케이션(앱) → 브라우저 또는 니오빌 관리 → 알림에서 허용한 뒤 다시 눌러 주세요.

    텔레그램 알림 (선택)

    1. 텔레그램에서 @BotFather를 찾아 대화를 시작합니다
    2. /newbot 입력 → 봇 이름(예: 니오빌 알림) → 아이디(영문, 끝은 bot, 예: niovill_alarm_bot)
    3. BotFather가 보내 준 토큰(숫자:영문 긴 글자)을 복사해 아래에 붙여 넣습니다

    봇:

    1. 알림 받을 사람이 각자 텔레그램에서 를 찾아 시작(/start)을 누릅니다
    2. 아래 받는 사람 찾기를 누릅니다
