텔레그램 알림

  1. 텔레그램에서 @BotFather를 찾아 대화를 시작합니다
  2. /newbot 입력 → 봇 이름(예: 니오빌 알림) → 아이디(영문, 끝은 bot, 예: niovill_alarm_bot)
  3. BotFather가 보내 준 토큰(숫자:영문 긴 글자)을 복사해 아래에 붙여 넣습니다

봇:

  1. 알림 받을 사람이 각자 텔레그램에서 를 찾아 시작(/start)을 누릅니다
